# 编辑器骨架灵活化设计（对标 lowcode editor-skeleton）

> 研究对象：`01-lc/lowcode-engine/packages/editor-skeleton`（编辑器布局/面板骨架）

> 目标：让 new-assembox-editor 的面板系统支持灵活的多形态注册、初始化、浮动/固定切换
> 配套：`04-lowcode插件设计借鉴分析.md`（插件层）、本文聚焦**骨架/面板层**

## 一、核心机制（四层抽象 + 双状态语义）

### 1.1 四种形态 + 两套状态语义（最关键设计）

| 形态 | type | 渲染产物 | 状态模型 | 典型场景 |
|---|---|---|---|---|
| **Widget** | `'Widget'` | 纯内容片段 | `show/hide`（独立布尔 `_visible`） | topArea logo、工具栏按钮 |
| **Dock** | `'Dock'` | 图标按钮（可跳转链接/动作） | `show/hide` | 语言切换、外链跳转 |
| **PanelDock** | `'PanelDock'` | 图标按钮 **+ 自动联动一个 Panel** | 按钮 `show/hide` + 面板 `active` | leftArea 组件库/大纲/源码 |
| **Panel** | `'Panel'` | 带标题栏面板 | **`active/inactive`（同容器互斥）** | leftFloat/leftFixed/right/bottom |

**核心分水岭**：
- `Widget/Dock` 用"独立显隐"（`_visible` 布尔，可同时多个）
- `Panel` 用"互斥激活"（`_actived`，同容器一次一个）
- Panel 的 `visible` 是 computed = `parent.visible && _actived`

> 用 `isWidget()/isPanel()/isPanelDock()` 标记位做鸭子类型判别，而非 instanceof，解耦类型判断。

### 1.2 三层架构

```
Skeleton（门面 + 工厂 + transducer 管道 + 全局注册表）
  └─ Area（封装 exclusive 语义：visible = 有激活项 / 独立布尔）
      └─ WidgetContainer（items 集合 + current + active/unactive 互斥）
          └─ 形态实例（纯状态 + 懒加载 body）
```

### 1.3 配置管道（最强扩展点）

```
skeleton.add(config)
  → parseConfig（展平 content 对象 → 顶层字段；幂等防重复解析）
  → configTransducers（注册式中间件，level 升序，插件可改写配置）
  → area 推断（Panel→leftFloat / Widget→main / 其它→left，免每次指定 area）
  → area.add → container.add → createWidget（按 type 工厂分支）
```

**createWidget 工厂分支**（按 type）：
- `/Dock$/.test(type)` → PanelDock? `new PanelDock` : `new Dock`
- `type === 'Panel'` → `new Panel`
- `type === 'Divider'` → `new Widget({content: Divider})`
- 兜底 → `new Widget`

### 1.4 PanelDock 双体分离（按钮与面板解耦）

- 按钮（leftArea）与面板（leftFloat/leftFixed）**分离注册**，靠 `panelName` 关联
- 构造时若有 content → 自动 `skeleton.add({type:'Panel', name:panelName, ...})` 创建关联 Panel
- `actived` = `panel.visible`（computed，按钮高亮响应式跟随面板）
- `panel` getter 延迟查找（`_panel || skeleton.getPanel(panelName)`），解耦创建顺序
- 交互：`togglePanel()` → `panel.toggle()`；`showPanel()/hidePanel()` → `panel.setActive(bool)`

### 1.5 浮动（leftFloatPane）vs 固定（leftFixedPane）

| | LeftFixedPane | LeftFloatPane |
|---|---|---|
| 定位 | `flex-shrink:0` 占布局列（宽 `--dock-fixed-pane-width:300px`） | `position:absolute`，`left: calc(left-area-width+1px)`，`z-index:820`，带阴影 |
| 显隐 | `lc-area-visible` class | 同左，exclusive→靠 current |
| 失焦关闭 | 无 | **FocusTracker** 白名单范围判定 |
| 拖拽改宽 | 禁用 | 允许（`enableDrag`） |

**toggleFloatStatus(panel)**（核心迁移）：
```
isFloat = panel.parent.name === 'leftFloatArea'
if (isFloat) { leftFloatArea.remove(panel); leftFixedArea.add(panel); leftFixedArea.container.active(panel) }
else         { leftFixedArea.remove(panel); leftFloatArea.add(panel);  leftFloatArea.container.active(panel) }
preference.set(`${panel.name}-pinned-status-isFloat`, !isFloat)  // 持久化，刷新恢复
```

**Panel.setActive 两侧互斥**：激活 float 区面板 → `leftFixedArea.container.unactiveAll()`；反之亦然。保证同一时刻只一侧有激活面板。

**FocusTracker 失焦范围判定**（精细交互）：
1. 点击在面板 shell 内 → 不失焦
2. 点击在 iframe 画布内 → 失焦
3. 点击在 `.lc-right-area` → 失焦
4. 点击不在 `.lc-workbench` 内（外部 popup）→ 不失焦
5. 点击在 `.lc-workbench-body` 内（排除上述）→ 不失焦
6. 点击在关联 PanelDock 按钮 DOM 内 → 不失焦

### 1.6 其他关键机制

- **index 排序**：items 按 `config.index` 升序渲染（控制顺序）
- **align 槽位**：topArea/toolbar 的 `left/center/right`；leftArea 的 `top/bottom`（CSS space-between 撑开）
- **懒初始化**：`inited` 标志 + `body` getter 首次访问才 `createContent`；未 inited 时 `setVisible(false)` 被忽略（避免永不渲染）
- **CSS 变量驱动布局**：`--left-area-width`/`--right-area-width`/`--dock-pane-width` + 媒体查询断点（1860px 大屏加宽）
- **区域显隐统一**：`.lc-area-visible` class 切换 display；exclusive 区域 visible 由 `container.current` 派生
- **事件上报在视图层**：模型纯状态，View 用 watch/DidUpdate 检测 last 值变化上报（PANEL_SHOW/HIDE、WIDGET_SHOW/HIDE 等），模型不耦合事件总线

## 二、标准接口（skeleton.add config）

```ts
skeleton.add({
  area: 'leftArea' | 'topArea' | 'centerArea' | 'rightArea' | 'bottomArea' | 'toolbar',
  type: 'PanelDock' | 'Widget' | 'Dock' | 'Panel',
  name: string,
  content: Component,              // 面板/按钮内容组件
  contentProps?: Record<string, any>,
  props: {                         // 按钮/显示配置
    align?: 'left' | 'center' | 'right' | 'top' | 'bottom',
    icon?, title?, description?,
    index?: number,                // 排序
    onClick?: () => void,          // Dock 点击（跳转/动作）
  },
  panelProps?: {                   // PanelDock 联动面板配置
    panelName?: string,
    area?: AreaName,
    floatable?: boolean,           // 是否可浮动
    width?, height?,
    hideTitleBar?: boolean,
    canSetFixed?: boolean,
  }
})
```

### 默认 9 个 Area 及配置

| Area | item 类型 | exclusive | defaultSetCurrent | 角色 |
|---|---|---|---|---|
| leftArea | Dock/PanelDock | false | false | 左侧图标栏 |
| topArea | Dock/Divider/PanelDock | false | false | 顶部栏 |
| subTopArea | 同上 | false | false | 二级顶栏 |
| toolbar | 同上 | false | false | 中部工具条 |
| **leftFixedArea** | Panel | **true** | false | 左侧固定面板 |
| **leftFloatArea** | Panel | **true** | false | 左侧浮层面板 |
| rightArea | Panel | false | **true** | 右侧设置面板 |
| **mainArea** | Widget/Panel | **true** | **true** | 主画布 |
| bottomArea | Panel | true | false | 底部面板 |

> `exclusive=true` 的区域：visible = `container.current != null`（有激活项才可见）。

## 四、新项目对比（已有 vs 缺失）

| 机制 | new-assembox 现状 | lowcode | 差距 |
|---|---|---|---|
| 形态 | Widget/Panel/PanelDock（**3 种**） | + Dock/Stage | 缺 Dock |
| exclusive 语义 | AreaImpl `exclusive:true` 但 **visible 是普通 `{value:boolean}`** | visible = `container.current != null`（派生） | visible 非派生 |
| 浮动/固定切换 | ❌ 无（area 固定） | toggleFloatStatus + preference | 缺 |
| FocusTracker | ❌ 无 | 白名单失焦关闭 | 缺 |
| configTransducers | ❌ 无 | 注册式配置中间件管道 | 缺 |
| area 推断默认 | ❌ 需显式 area | Panel→leftFloat / Widget→main | 缺 |
| index 排序 | ❌ 按 add 顺序 | config.index 升序 | 缺 |
| align 槽位 | 弱（leftArea top/bottom） | left/center/right/top/bottom | 不完整 |
| PanelDock 双体 | ✅ 按钮+联动 panel | + panelName 延迟关联 | 已有（关联简单） |
| 懒初始化 | ✅ inited（简单） | + body 首次 createContent | 已有 |
| CSS 变量布局 | 部分 | 完整变量 + 断点 | 部分 |

**结论**：新项目骨架**基础三层已有**（Skeleton/Area/Container/Widget），缺**灵活性的关键机制**：Dock 形态、exclusive 派生 visible、浮动固定切换、配置管道、area 推断、index/align。

> 上次源码/历史面板"无法使用"（area=leftFloatArea 高度塌陷）就是 **exclusive visible 非派生**的典型症状——浮动区没激活面板时仍占位/塌陷。补齐 exclusive 派生 visible 可根治此类。

## 五、灵活化实现方向（按优先级）

### P0｜补齐灵活注册核心

#### P0-1 Dock 形态
独立图标按钮（onClick 跳转/动作，非联动 panel）。`WidgetType` 加 `'Dock'`，`createWidget` 分支，渲染 DockView（图标+tip+onClick）。

#### P0-2 exclusive visible 派生
AreaImpl.visible 改 computed（exclusive 时 = `container.current.value != null`）。leftFloat/leftFixed/main/bottom 靠"有无激活面板"自动显隐，根治区域塌陷。

#### P0-3 area 推断默认
skeleton.add 未指定 area 时按 type 推断：
- PanelDock/Panel → leftFixedArea
- Widget → centerArea
- Dock → leftArea

### P1｜浮动/固定 + 失焦（体验关键）

#### P1-1 toggleFloatStatus
面板在 leftFixedArea ↔ leftFloatArea 间迁移 + setActive + 两侧互斥。

#### P1-2 FocusTracker
浮动面板失焦关闭（白名单范围：画布/设置区→关，dock 按钮/外部 popup→不关）。

#### P1-3 index 排序 + align 槽位
items 按 index 排序；topArea/toolbar 支持 left/center/right 分组渲染。

### P2｜扩展管道

#### P2-1 configTransducers
注册式配置中间件（`registerConfigTransducer(fn, level, id)`），插件创建前改写配置。

#### P2-2 preference 持久化
浮动/固定状态、面板宽度 localStorage 恢复。

#### P2-3 PanelDock panelName 延迟关联
panel getter 延迟查找，解耦按钮/面板创建顺序。

## 六、落地接口预览（新项目骨架增强 TS）

```ts
// skeleton/types.ts 增强
export type WidgetType = 'Widget' | 'Panel' | 'PanelDock' | 'Dock';

export interface WidgetConfig {
  type: WidgetType;
  name: string;
  area?: AreaName;           // 可选（按 type 推断）
  content?: VueComponent;
  contentProps?: Record<string, any>;
  props?: {
    align?: 'left' | 'center' | 'right' | 'top' | 'bottom';
    icon?: any; title?: string; description?: string;
    index?: number;           // 排序
    onClick?: () => void;     // Dock 点击
    href?: string;            // Dock 跳转
  };
  panelProps?: {
    panelName?: string;
    area?: AreaName;
    floatable?: boolean;      // 可浮动
    width?: number; height?: number;
    hideTitleBar?: boolean;
  };
}

// Skeleton 增强
class Skeleton {
  add(config: WidgetConfig): Widget {
    const parsed = this.parseConfig(config);
    const transformed = this.runTransducers(parsed);   // 配置管道
    const area = transformed.area ?? inferArea(transformed.type);  // 推断
    return this.getArea(area)!.container.add(transformed);
  }
  toggleFloatStatus(panel: Panel): void { /* leftFixed ↔ leftFloat 迁移 */ }
  registerConfigTransducer(fn: (c) => c, level: number, id: string): void {}
  private runTransducers(config): WidgetConfig { /* level 升序应用 */ }
}

// Area visible 派生
get visible() {
  return this.exclusive
    ? this.container.current.value != null
    : this._visible.value;
}
```

## 七、Vue3 落地映射表

| lowcode（React + MobX） | Vue3 等价 |
|---|---|
| `@obx.ref _visible` | `ref(false)` |
| `@computed` | `computed()` |
| `createContent(Comp, props)` | `h(component, props)` 或 `<component :is>` |
| `<WidgetView widget>` 包装层 | 函数式组件 / defineComponent render wrapper |
| `componentDidUpdate` 检测 last 值 | `watch(() => state, ...)` |
| `WidgetContainer.items(@obx.shallow)` | `shallowRef([])` |
| `createContext(Skeleton)` | `provide/inject` |
| FocusTracker | `useFocusOut(el, onLost, range)` composable |
| eventBus.emit | mitt / 自建 emitter |
| preference.set/get | localStorage / Pinia persisted |
| transducer pipeline | `pipe` 函数组合 + 注册数组 |

**核心架构原则**：保持"配置 → 工厂 → Area 容器 → 形态实例"四层不变；MobX 响应式换 Vue3 `ref/computed/shallowRef`；React 视图换 Vue3 组件 + `watch`。**exclusive 互斥、PanelDock 双体分离、浮动/固定迁移、transducer 管道**四个机制可几乎原样移植。

## 八、关键借鉴要点速查

1. **双状态语义**：show/hide（Widget/Dock）vs active/inactive（Panel）—— 两类 UI 用不同状态模型
2. **exclusive 区域**：visible = 有激活项（leftFloat/leftFixed/main/bottom）；普通区可同时多个（left/top/right）
3. **PanelDock 双体**：按钮与面板分离注册，panelName 关联，actived 响应式派生
4. **浮动/固定双区**：迁移 + 持久化 + 两侧互斥 + FocusTracker 白名单失焦
5. **配置管道**：parseConfig + transducers（插件改写配置）
6. **area 推断 + index + align**：免配置 + 排序 + 槽位
7. **懒初始化**：body 首次访问才创建，未 init 忽略 hide
8. **视图上报事件**：模型纯状态，View watch 检测变化上报
